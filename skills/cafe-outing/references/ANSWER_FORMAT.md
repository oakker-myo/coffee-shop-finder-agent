# Answer format

**<Cafe name>**: <one-line reason>.
- Open: until <closes>
- Walk: <walk phrase from nearest_shops>
- <Drink>: £<price>
- Also good: <second cafe> (<short reason>)

Rules:
- Copy the tools' phrases (walk, closes, note) word for word.
- Leave out any line you have no data for. Never fill it in.
- If nothing is open, say so and give the earliest next_open instead.
